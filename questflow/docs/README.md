# Documentation

Quest Flow was developed under the working name **Forever Codex**. The `CODEX_*.md` notes here are the design and development history of that work and keep the original name on purpose; they describe how the addon came to be and why decisions were made, not the public product.

The ones that matter for releasing and for the data:
- `RELEASING.md`: how a build is versioned, packaged and released.
- `CODEX_DATA_SOURCES.md`: every data source, its licence, and the provenance decisions.
- `CODEX_ARCHITECTURE.md`: how the addon fits together.
- `CODEX_TEST_GUIDE.md`: how the real-client checks were done during development.

For users: see the repository README. For the release candidate: `../../docs/release/`.
